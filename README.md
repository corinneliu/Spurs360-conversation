# Spurs360

A presenter-driven demo console for **Tottenham Spur**: one unified fan profile (Alex Chen, One Spur Gold) powered by Salesforce Data 360, Service Cloud, Marketing Cloud, and Agentforce.

## Run locally

```bash
cd Spurs360
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Walk the story

Use the **presenter bar** at the bottom (or keys `1` `2` `3` `4` and `←` `→`):

1. **Act I — Unified profile** — Open Alex Chen, Gold summary card, Ticketmaster + Spurs Shop timeline.
2. **Act II — Stadium 365** — Tottenham Spur Stadium venue hire, Corporate Event Prospects segment, stadium tour journey.
3. **Act III — Agentic service** — Ask Spurs seat transfer for Indianapolis Colts v Washington Commanders on 4 October, then the high-touch damaged-merch case with Next Best Action.
4. **Act IV — Agentic context** — Next morning, Alex forgot the food & drinks package. Ask Spurs already knows the colleague is Priya Nair.

This app is a simulated Spurs360 (authored demo data). It does not call a live org.
